# 气律实验室

[繁體中文](./README.zh-TW.md) · [English](./README.en.md)

## 项目简介

气律实验室是一款面向热学与分子运动实验的 Windows 桌面软件，包含标准硬球分子模拟、理想气体关系验证，以及绝热膨胀法和活塞振动法两套空气比热容比实验。

本仓库是公开发行仓库，提供 Windows 安装包、自动更新资产和多语言版本说明。经过匿名处理的版本源码与逐提交历史发布在 [gas-laws-lab-history](https://github.com/yanshi-qibixunchang/gas-laws-lab-history)；研究报告工作材料不属于公开源码镜像。

## 自动更新

打开应用内“帮助”→“关于”，点击“检查更新”。稳定更新必须在同一个 GitHub Release 中同时包含：

- `heat-capacity-lab-setup-6.4.2.exe`
- `heat-capacity-lab-setup-6.4.2.exe.blockmap`
- `latest.yml`

如果自动更新失败，可手动下载最新安装包并覆盖安装。除非 Release 明确说明存在不兼容，否则不需要先卸载。

## 6.4.1 更新重点

6.4.1 完善两种热容比实验的真实／理想条件、空气／氦气和逐步学习流程，修复活塞主周期识别、断电转场与按显示值精确计算，并完成工作台架构拆分、保存恢复、性能和报告改进。

- **两种实验统一真实／理想与空气／氦气**：绝热膨胀法与活塞振动法支持真实／理想实验条件及空气／氦气。理想条件消除预置的环境、观测与损耗扰动，仍需按相同流程操作、处理和计算；错误操作仍有物理后果，理想条件只提供过程诊断，不生成数值评分。
- **按熟悉程度逐步学习并保留自由实验**：首次使用可分别选择是否熟悉两种实验，需要学习时按实验顺序逐步解锁演示、引导和自由模式。演示与未完成引导不作为自由实验保存；已完成引导可复查，自由模式数据保留到完整重置，切换模式不会覆盖自由实验。
- **至少两个主周期，断电后进入计算**：引导框选至少两个可信主周期，通过主周期与主峰／主谷识别排除局部小峰；含糊曲线不会被凑成足够周期。三组处理后关闭电源会正常进入拟合与计算，不再回到参数设置。
- **逐步使用界面显示值，严格判定正确答案**：周期平方、拟合、截面积、比热容比和相对误差均使用界面已经显示并舍入的数据逐步计算。修复周期平方的十进制中点舍入，统一表格和拟合坐标；精度合规但仅接近正确值的答案仍判错，不使用容差或隐藏高精度答案。
- **明确工作台职责与撤销范围**：完成工作台文件、实验控制、只读展示、教学、保存退出和兼容读取的职责拆分，保持实验状态、采样及存档权威一致。绝热膨胀资料窗口整体关闭现在可以独立撤销和重做，恢复标签顺序而不回滚实验过程。
- **修复更新清单解析依赖**：更新清单解析使用 js-yaml 4.3.2 补丁版，保留正常更新信息、中文版本说明及异常输入限制，并同步第三方许可记录。
- **保留原始记录，更新失效计算**：继续沿用原应用 ID、安装身份、用户资料目录和公开更新仓库。旧活塞原始记录及有效周期读数保留；受旧舍入规则影响的拟合与下游计算会要求重新完成，不能复用过时答案。请在升级前备份重要实验。

## 实验模块

### 空气比热容比（绝热膨胀法）

支持演示、引导和自由模式，覆盖调零、打气、等待、快速放气、恢复、U₀/U₁/U₂ 记录、多组实验、计算、评分、过程回顾和报告导出。

### 空气比热容比（活塞振动法）

6.4.0 在 6.3.1 已完成的连续热—传感—虚拟手采集模型上补齐课程结果闭环：

- 自由模式新增逐次过程回顾与评分。切换实验次数会同步更新仪器操作时间条、正式曲线、周期选区、关键证据和可展开评分明细。
- 普通操作、保存曲线等重点节点沿用另一热容比实验的颜色、节点和悬浮信息规则；再次按压、重置、触底、软管、电源及双手松开时间差会按实际发生情况记录。
- 完成活塞振动法 PDF 实验报告，精简呈现实验文件、逐次记录、周期、拟合、最终计算、过程证据和评分，不额外添加原理或公式章节。
- 自由模式右侧参数栏开放环境压强、环境温度、采样率、下降触发线和键鼠可视化；经风险确认后可编辑已建模的高级参数，首条正式曲线保存后整套配置随实验文件固化。
- 下降触发线范围随环境压强按相同比例缩放，标准环境仍保持已审核的 `96–130 kPa` 窗口，并受传感器量程约束。
- 过程回顾接入后，实时采集仍可暂停、保存和继续；监测点、监测线及未触发后的再次按压保持可用。

### 标准模拟与理想气体

标准模拟提供硬球分子运动、实时采样和结果图表。理想气体模块支持 `P-T`、`P-V` 和 `P-N` 关系扫描、拟合与验证。

## 常见问题

**升级后会丢失旧实验吗？**  
继续沿用原应用 ID、安装身份、用户资料目录和公开更新仓库。旧活塞原始记录及有效周期读数保留；受旧舍入规则影响的拟合与下游计算会要求重新完成，不能复用过时答案。请在升级前备份重要实验。

**为什么实时数据区只显示“电源关闭”？**  
这是活塞振动法的正常关机状态，请先按下 3D 仪器上的电源开关。

**自动更新失败怎么办？**  
从本仓库 Releases 手动下载 6.4.2 安装包并覆盖安装，同时保留用户资料目录。

**为什么 Windows 可能显示安全警告？**  
Windows 可能对来自互联网且尚未积累足够信誉的安装包显示提示，请先核对仓库地址和 Release 文件名。
