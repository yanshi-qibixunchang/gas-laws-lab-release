## 本次更新

- **网页版桌面下载入口**：网页版标题栏和关于窗口增加 Windows 桌面版下载入口，确认后打开 6.4.4 安装包；说明网页版与桌面版分别保存进度，下载不会自动迁移实验。
- **网页版导出提示与环境说明**：网页版导出报告、图像和表格时明确提示使用桌面版；关于窗口、导出状态和初始日志使用一致的三语说明。保留数据就绪检查，并在打开绝热法报告选择窗口前检查引导限制。
- **浏览器只读实验信息**：支持相关接口的浏览器可读取界面已显示的当前实验名称、类型和所选面板。接口不提供答案或隐藏模拟值，不启动实验、不修改学习进度；不支持该接口的浏览器仍可正常使用。
- **6.4.4 桌面更新与兼容**：同步 Windows 安装包、差分文件和更新元数据。桌面版保留本地导出、检查更新、软件身份和资料目录；实验模型、计算公式及存档格式沿用 6.4.3。
